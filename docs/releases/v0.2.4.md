# renewal v0.2.4

Two fixes from the first real Windows install. If you have 0.2.3 installed and
working, you do not need this; if 0.2.3 told you it failed, this is why.

## "Setup did not finish", when it had

`bootstrap.ps1` ended with `exit $LASTEXITCODE` after calling `install.ps1`
with `&`. A script call does not set `$LASTEXITCODE` — so what got returned
was whatever the last *native* command inside `install.ps1` happened to leave
behind, usually non-zero for a perfectly ordinary reason. The installer then
reported a failure over a complete, working installation, which is exactly
what it looked like: an error message, and everything present anyway.

`install.ps1` now runs as a child process, so the exit code is its own.

## No login was ever created

The installer runs PowerShell through `nsExec`, which has no console attached.
The step that asks for the first account used `Read-Host`, which in that
context returns nothing — so the account was skipped in silence, and the first
thing anybody saw was a login page they could not get past.

Two changes:

- `install.ps1` detects that there is nothing to type into, says so, and
  points at `create-account.cmd` instead of pretending to ask.
- **`create-account.cmd`** is new: double-click it, type an email address, type
  a password twice. The installer's last page now offers to run it.

The password is still never passed as an argument — it would land in the
command history and be readable by every other account on the machine.

## If you already installed 0.2.3

Nothing is wrong with it. Finish it by hand in the installation folder
(`%LOCALAPPDATA%\Renewal`):

```powershell
notepad .env                                              # set ANTHROPIC_API_KEY
.venv\Scripts\python -m scripts.add_user you@example.com  # make a login
```

Then use the Renewal icon. Or install 0.2.4 over the top — it keeps the
database, the documents and the `.env` that are already there.

## Unchanged

Everything else is 0.2.3. Extraction accuracy on real documents is still
unmeasured and no real mailbox has been polled.
