# renewal v0.2.5

The installer keeps a log.

Two installs have now failed on Windows, and both times the only thing needed
to fix them — what the installer actually said — was the first thing lost. Run
from the `.exe` there is no window left to read. Run from `install.cmd` the
window can be closed before anybody writes it down.

Every attempt is now transcribed to:

```
runtime\install.log
```

next to the application, appended to rather than overwritten, so a second
attempt does not erase the evidence from the first. When something fails, both
the wizard and the console name that file and say to send it.

Nothing else changed. If 0.2.4 installed cleanly for you, this adds nothing.

## When it fails

Send `runtime\install.log`. That is the whole of it.

To see the same thing live, double-click `install.cmd` in the installation
folder rather than re-running the `.exe` — same work, output on screen, and it
reuses anything already downloaded instead of fetching 290 MB again.
