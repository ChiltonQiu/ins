# renewal v0.2.3

**Download `Renewal-0.2.3-setup.exe` and double-click it.** That is the whole
installation.

The code here is the same as [v0.2.2](v0.2.2.md) — that release got its
installer attached after it was published, and this one is cut with it from
the start so there is one obvious thing to hand somebody. Everything in
[v0.2.2](v0.2.2.md), [v0.2.1](v0.2.1.md), [v0.2.0](v0.2.0.md) and
[v0.1.0](v0.1.0.md) still applies, including the warnings.

## What the installer does

It installs **for your account only**, into `%LOCALAPPDATA%\Renewal`, and
**never asks for an administrator password** — not for itself, and not for
anything it installs:

- **Python**, when the machine has none, is installed per-user into `AppData`.
- **PostgreSQL**, when the machine has none, is not installed at all. Its
  binaries are unpacked inside the application folder, `initdb` makes a
  cluster there, and it listens on **127.0.0.1:5433**. No Windows service, no
  superuser password, nothing registered, and the standard port left free for
  a PostgreSQL that may already own it.
- A computer that already has either one is left alone and uses it.

On a machine with neither, it downloads about **315 MB** and can take ten
minutes; the install log stays on screen throughout, because an installer that
looks frozen is one somebody kills halfway through creating a database. On a
machine that has both, it downloads nothing.

It appears in Add/Remove Programs. Uninstalling asks before removing the
folder, because that folder is also where the database and every filed
document live.

## After it finishes

One value has to be filled in before the application will start:
`ANTHROPIC_API_KEY` in the `.env` file in the installation folder. The
application builds its model client when it loads, so it stops before serving
anything without one.

Then use the **Renewal** icon on the desktop. It opens a browser at the
application, starting it — and the private database — first if they are not
already running. It also starts itself when that account signs in.

## It has not been run on Windows

It was built on Linux and there is no Windows machine here, so this is correct
by construction rather than by test. Expect to meet at least one of:

- **SmartScreen** warning about an unknown publisher — the installer is
  unsigned. *More info → Run anyway.*
- The Python step looking stuck. It is a silent installer; give it a minute.
- The PostgreSQL download failing on a flaky connection. Running it again
  resumes from what was already fetched.

If it misbehaves, the tarball does exactly the same work with its output
visible: unpack `renewal-0.2.3.tar.gz`, double-click `install.cmd`, and the
window pauses at the end so the error survives. That window, and the end of
`runtime\postgres.log` if the database was what failed, are the two useful
things to capture.

## Unchanged, and still the point

Extraction accuracy on real carrier documents is unmeasured, and no real
mailbox has been polled. This release is about getting the thing running in
front of somebody. Whether it is any good is what `scripts/usage_report.py`
answers, a week later.
