# renewal v0.2.1

Windows, without a terminal. Everything in
[v0.2.0](v0.2.0.md) and [v0.1.0](v0.1.0.md) still applies, including the
warnings — this release changes how it is installed, not what it does.

## Installing on Windows

Download `renewal-0.2.1.tar.gz`, unpack it, and **double-click `install.cmd`**.

That is the whole of it. A `.ps1` cannot be started by double-clicking —
Windows opens it in an editor, and a downloaded one is blocked by the
execution policy besides — so the one file to find in the folder is a `.cmd`
that runs the installer for you.

You still need three things on the machine first, and the installer stops with
the download link for whichever is missing:

| | |
|---|---|
| **Python 3.11+** | Tick **"Add python.exe to PATH"** in its installer |
| **PostgreSQL 15+** | Remember the password you set for the `postgres` user |
| **Tesseract** | Optional. Without it a scan is stored but never read |

And afterwards, one value in `.env`: `ANTHROPIC_API_KEY`. The application
builds its model client when it loads, so it will not start without one.

## What you get when it finishes

- A **Renewal icon** on the desktop and in the Start Menu.
- The application **starts itself when that account signs in**, so after the
  first install nobody has to see a terminal again. The icon opens a browser
  at it, starting it first if it is not already running.
- `TESSERACT_CMD` filled in automatically when Tesseract is installed
  somewhere PATH does not look, which on Windows is the normal case — without
  it every scanned page fails.

`RENEWAL_AUTOSTART=0` before running the installer skips the sign-in task.
`schtasks /Delete /TN Renewal /F` removes it later. The icon runs
`scripts\start.ps1`, which is safe to run twice: if something is already
listening it opens a browser rather than starting a second copy that cannot
bind.

## Read this before you try it

**None of this has been run on Windows.** There is no Windows machine and no
PowerShell runtime where it was written, so the scripts are careful rather
than proven. What is verified is the pair of assumptions the launcher rests
on: that `python -m uvicorn renewal.app:app` starts the server, and that
`/login` answers `200`, which is how it decides the application is up.

Expect one or two small fixes on first contact. If something goes wrong, the
two things worth capturing are:

1. **The whole `install.cmd` window.** It pauses at the end for exactly this
   reason — the error is above the pause.
2. **What the application says when started by hand**, which is where a
   configuration problem actually names itself:

   ```powershell
   cd <the folder>
   .venv\Scripts\python -m uvicorn renewal.app:app --port 8000
   ```

The most likely failures, in order: `ANTHROPIC_API_KEY` empty in `.env`;
PostgreSQL installed but not running, or its user unable to create a database;
Python present only as the Microsoft Store stub, which answers `python` on a
machine with no Python (the installer skips it and says so).

## Everything else

Unchanged from 0.2.0. Extraction accuracy on real carrier documents is still
unmeasured, and no real mailbox has been polled. This release makes it easier
to get the thing running in front of somebody; it does not make it right.
