# renewal v0.3.0

**Download `Renewal-0.3.0-setup.exe` and double-click it.** Upgrading from
0.2.6: run it over the old install, into the same folder. Your data stays.

`.env` is no longer part of the product. Every earlier release ended with
"put the key in `.env`", which for somebody at an agency is where the product
ended.

## What is new

- **It starts with nothing set up.** No key is needed to boot. Documents that
  arrive first are stored and searchable, and are read once there is a key.
- **A setup page, `/setup`.** Three cards, each tested before it is saved:
  - **AI** — paste the Anthropic key; it makes one small request to check it.
  - **Reading mail** — an address and an app password (Gmail is filled in,
    any IMAP host works), then a folder picked from the ones that exist, and
    whether to start from mail arriving *from now on* or from everything
    already there.
  - **Daily summary email** — optional, sent from the same account.

  Changes take effect at once, with no restart. Every page says
  *Finish setup* until the first two are done.
- **Updates from the page.** The setup page says which version this is and
  whether a newer one exists. On Windows, *Update now* downloads the new
  installer, checks it against the release's checksums, backs up the database,
  and reinstalls and restarts in place. `runtime\update.log` says what it did.

## Where the secrets go

What is typed into `/setup` is written to `.env` and nowhere else: not the
database, not its backups, not back onto any page. A saved password shows as
*saved*; leaving the field blank keeps it.

## What it asks the internet

Once at start and every twelve hours it asks GitHub whether a newer release
exists. That tells GitHub the office's IP address and nothing else. Set
`UPDATE_CHECK=false` in `.env` to stop it. `PRIVACY.md` has the detail.

## What it does not do

- **Microsoft 365 / Outlook mail.** Its IMAP needs OAuth, which this does not
  do. Gmail and ordinary IMAP hosts only.
- **Other AI providers from the page.** OpenAI, Grok, local models and the
  rest still work, configured in `.env` by hand.
- **One-click update outside Windows.** Elsewhere the page links to the
  release.

## Tested

On a clean Windows runner, on every push: install with no key, the setup page
and its banner render, and the update button is pressed for real against a
release served locally — backup made, installer run, application back up.

Not tested by anyone: the setup cards against a real Gmail account and a real
Anthropic key, and the wizard's pages. The first person to use it is the test.
